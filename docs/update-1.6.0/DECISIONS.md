# 1.6.0 implementation decisions

Log every choice SPEC.md did not fix exactly. Format: `YYYY-MM-DD · Tn.m · decision · why`. Tuned constants go here with their harness result.

- 2026-11-04 · T0.1 · Hand-off docs live in `docs/update-1.6.0/`; owner text copied verbatim to `OWNER_WORDS.md`. · Requested by the owner so any agent can resume exactly.
- 2026-11-04 · T0.2 · Commands are `{ name, args }` keyed into `GAME_COMMANDS` (`src/game/commands.ts`), which maps names straight to store reducers plus 4 composites (`useBagItem`, `catchWithBall`, `autoAttackStep`, `queueAction`). Widgets call `submitGameCommands` (`src/game/commandChannel.ts`); the index host runs `startCommandHost`. · Closures can't cross iframes; reusing reducer names keeps every action's logic unchanged.
- 2026-11-04 · T0.2 · Ack = a `SYNC_BROADCAST_KEY` broadcast carrying `ack: nonce`. Timeout 2.5 s → the widget writes directly; after one unanswered command the iframe writes directly for the rest of its life. The nonce is stored in the save (`recentCommandNonces`, last 30) so a late host delivery can't double-apply. · Keeps 1.5.0 behaviour as a safety net on hosts that don't deliver broadcasts to the index widget.
- 2026-11-04 · T0.2 · `AppEvents.MessageBroadcast` is spelled `'messaging.broadcast'` in commandChannel.ts (SDK 0.0.14 value) so Node tests don't load the SDK. Listeners are registered with both `undefined` and the channel key; nonce dedupe makes a double delivery harmless.
- 2026-11-04 · T0.3 · The area check runs when the next wild spawns (`nextArea` in encounter.ts): the arena stays for the area's 5–8 encounters and moves on with the first wild after the last one is resolved. Same visible result as "change after resolving", but the crossfade lands with the new wild's intro instead of mid-study. The scene-change shake was removed entirely (`FX_TIMELINES.scene`, `sceneShake`).
- 2026-11-04 · T0.3 · Area chip text = the scene's existing name (`battleSceneName`, e.g. "→ Forest Trail"); `area.isNew` is true only for the first wild in a new area. Trainer battles don't count toward an area.
