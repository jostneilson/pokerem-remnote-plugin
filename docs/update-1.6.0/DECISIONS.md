# 1.6.0 implementation decisions

Log every choice SPEC.md did not fix exactly. Format: `YYYY-MM-DD · Tn.m · decision · why`. Tuned constants go here with their harness result.

- 2026-11-04 · T0.1 · Hand-off docs live in `docs/update-1.6.0/`; owner text copied verbatim to `OWNER_WORDS.md`. · Requested by the owner so any agent can resume exactly.
- 2026-11-04 · T0.2 · Commands are `{ name, args }` keyed into `GAME_COMMANDS` (`src/game/commands.ts`), which maps names straight to store reducers plus 4 composites (`useBagItem`, `catchWithBall`, `autoAttackStep`, `queueAction`). Widgets call `submitGameCommands` (`src/game/commandChannel.ts`); the index host runs `startCommandHost`. · Closures can't cross iframes; reusing reducer names keeps every action's logic unchanged.
- 2026-11-04 · T0.2 · Ack = a `SYNC_BROADCAST_KEY` broadcast carrying `ack: nonce`. Timeout 2.5 s → the widget writes directly; after one unanswered command the iframe writes directly for the rest of its life. The nonce is stored in the save (`recentCommandNonces`, last 30) so a late host delivery can't double-apply. · Keeps 1.5.0 behaviour as a safety net on hosts that don't deliver broadcasts to the index widget.
- 2026-11-04 · T0.2 · `AppEvents.MessageBroadcast` is spelled `'messaging.broadcast'` in commandChannel.ts (SDK 0.0.14 value) so Node tests don't load the SDK. Listeners are registered with both `undefined` and the channel key; nonce dedupe makes a double delivery harmless.
- 2026-11-04 · T0.3 · The area check runs when the next wild spawns (`nextArea` in encounter.ts): the arena stays for the area's 5–8 encounters and moves on with the first wild after the last one is resolved. Same visible result as "change after resolving", but the crossfade lands with the new wild's intro instead of mid-study. The scene-change shake was removed entirely (`FX_TIMELINES.scene`, `sceneShake`).
- 2026-11-04 · T0.3 · Area chip text = the scene's existing name (`battleSceneName`, e.g. "→ Forest Trail"); `area.isNew` is true only for the first wild in a new area. Trainer battles don't count toward an area.
- 2026-11-04 · T0.4 · `formatCoins` lives in `src/ui/format/coins.ts` (pure, also used by game messages such as the trainer loss fee); `<Coins value prefix>` (`src/ui/components/Coins.tsx`) renders the short form with the exact amount in `title`/`aria-label`. Negative amounts show `−₽1.5k`.
- 2026-11-04 · T0.5 · Trainer-battle, quest and achievement payouts stay in their own modules until T5.1 rewires every reward through balance.ts; T0.5 moved the wild/study/XP weights and rarity constants only (encounters.ts re-exports rarity.ts so imports keep working).
- 2026-11-04 · T0.6 · Harness = `src/game/sim/balance.ts` (`runBalance`, `runMatrix`, `evaluateBands`); report script `scripts/balance-tune.ts` (`npm run balance:tune`, add `--quick` for 2 seeds × 30 days ≈ 90 s; full 20 seeds × 60 days ≈ 15 min, run it in the background). It fakes `Date` (1 day per 100 cards) so quests and streaks roll over, and books coins per source by wrapping each action. `transferOut`/`storageCap` pick up `transferPokemon`/`storageCapacity` from the store automatically once T4 adds them. Grid-search tuning is added in T5.7.
- 2026-11-04 · T0.7 · Tier fix done in `species.ts` (`withClassTier`), not in the generated `pokedex.ts`: any non-ordinary classification sets the tier (legendary → Legendary, mythical → Mythical, ultra-beast → Ultra). Fixed a pre-existing flaky store test by seeding its defeat.
- 2026-11-04 · T1.2 · Galarian birds appear **whichever generations are enabled** (they're every team's mascot, and the default setting is Gen 1 only, which would otherwise mean no birds ever). Bird roll comes before the legendary roll; legendary pool excludes the birds.
- 2026-11-04 · T1.1 · `spawnEncounter`'s `rarityBonus` (faster custom pacing) no longer raises event odds, since rarity is per encounter by L1. `shinyOddsForPacing` and its test were removed; `rarity.test.ts` replaces them.
- 2026-11-04 · T1.3 · "Rare in the wild" non-legendaries = everyday species with base catch rate ≤ 45 (pseudo-legendaries, fossils, most final stages): weight ×0.5 (starters keep their ×0.25). The uncaught-bias completeness check now ignores event species.
- 2026-11-04 · T1.4 · While the party average is ≤ 5 every wild uses the "near" rule (no Lv1 filler for brand-new players). Natural-level wilds: species picked at avg−4, level uniform in [minWildLevel, avg−4]. `encounterBaseLevel` (whole-party mean) also sets trainer team levels. Wild HP scale 0.65 → 0.70 to keep the "wild fights 2–4 turns" band (weaker natural wilds pulled the average to 1.97).
- 2026-11-04 · T1.5 · L6 curve implemented exactly as the formula. SPEC's example "9.9% at 25% HP" is a rounding slip (the formula gives 10.2%); the other points match (2.0 / 4.7 / 17.3 / 25%). Tests assert the formula.
- 2026-11-04 · T1.5 · The legendary-class curve ignores type-advantage and trainer-tier catch bonuses (L6 lists only ball and status). Trainer catch of an everyday Pokémon now applies the normal status multiplier (×2 / ×1.5).
- 2026-11-04 · T2.1 · `src/game/engine/xpShare.ts` is the one place XP is scaled: `scaledXp(state, mon, base)` = base × catch-up × buddy × doubler, with fractions rounded at random in proportion (so 1.6 XP/card averages 1.6). Study XP: `studyPerCard` 1.6 for every member, lead ×1.2 (the 40/40/20 rolls are gone). KO split goes only to bench members with HP > 0; with none, the lead keeps 100%. Per-hit fight XP stays the lead's. Trainer battles now also apply `fightMult` (they didn't before). Appendix T start values set: knockoutMult 0.7, fightMult 0.7, typeShareMult 0.8 (typeShareMult is wired in T2.5).
- 2026-11-04 · T2.1 · Quick harness after XP Share, before tuning (Medium): party avg L10.8 / L17.1 / L45.0 at 500 / 1k / 3k cards (targets 15 / 22 / 38). Early too slow, late too fast; T5.7's grid search tunes it.
- 2026-11-04 · T2.2 · Catch-up uses the party only (storage Pokémon get no catch-up). The tag shows on party cards whenever the gap is > 0.
- 2026-11-04 · T2.3 · `starterId` backfill orders by the timestamp in the owned id (`pk_<ms>_…`), since owned Pokémon have no `caughtAt`; ids without a timestamp sort last.
- 2026-11-04 · T3.1 · Grunt types are limited to types with ≥ 3 everyday species in the enabled generations (Gen 1 alone has no Dark Pokémon, for example). `typesBeaten` resets once all 18 are beaten; beating the Leader resets only `gruntWins`. Grunts are `standard` tier, the Leader `elite` (elite AI and catch tier). Rocket battles still count in trainer stats. Grunt className "Rocket Grunt", Leader "Rocket Leader" + displayName "Corvin". Grunt trainer XP 60, Leader 150 (standard 45 / elite 120).
- 2026-11-04 · T3.4 · The Leader's prize is rolled when the Leader battle starts (stored on the battle as `prize`) and becomes the wild encounter when the post-win battle is closed (any close path). It has a full (owned-style) HP pool, can't be knocked out, waits after a lead faint and never wanders off; Run gives it up. Mythicals in the pool are fine (L15 says legendary or mythical).
- 2026-11-04 · T3.5 · Every trainer Pokémon (not just Rocket) can be shiny at 1/250, per A3 "Trainer and Rocket Pokémon can now be shiny". A caught shiny stays shiny; a shiny legendary-class trainer Pokémon is a sure catch.
- 2026-11-04 · T3.2 · The Rocket Radar chip appears once `state.rocket` exists (after the first Rocket win), so brand-new players aren't shown a system they haven't met (A6). On Play it sits under the trek strip, so it's hidden while an encounter is on screen.
- 2026-11-04 · T3.6 · Giving up the prize needs the sidebar's two-tap Run ("Run" → "Give up"). Every other Run path (queue strip, popup, RemNote command, the R key) is refused by `runFromEncounter` with a message, so a stray tap can't lose it. The intro overlay is dismissed by a React timer (1.8 s, or 1 s still under reduced motion), never blocks taps, and shows on the challenge (team select) screen.
- 2026-11-04 · T4.1 · Species data has only Common/Baby/Ultra/Legendary/Mythical tiers, so the transfer table's Uncommon and Rare come from catch rate: everyday species with catch rate ≤ 45 or in a starter line = Rare, ≤ 120 = Uncommon, else Common (`engine/transfer.ts transferTier`). A plain Common's payout is clamped to ₽99 before the shiny/HUNDO multipliers ("Common < 100 always"). Transfer XP goes through `scaledXp` (doubler, catch-up, buddy). Transferring the buddy sets `starterId: ''` (= no buddy) so the backfill can't pick a new one; `totalTransferred` counts transfers for achievements. Transfers are refused while that Pokémon is fighting a trainer.
