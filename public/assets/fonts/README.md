# PokéRem Pixel

`pokerem-pixel.ttf` is a derivative of the bundled Pixelify Sans variable font.
Only the outline and weight interpolation of U+0035 (`5`) are changed: a flat
top bar, upright left stem and open lower bowl replace the ambiguous original.
All other glyphs, character mappings and advance widths are preserved.
The family is renamed **PokeRem Pixel** and retains weights 400–700.

1.1; see `PixelifySans-OFL.txt`. Original copyright: Copyright 2021 The Pixelify
Sans Project Authors (https://github.com/eifetx/Pixelify-Sans).
Digit-five modification: Jost Neilson / PokéRem, 2026.

Regenerate with `scripts/generate-clear-five.py` (fonttools 4.63.0).
Normal plugin builds embed the committed derivative through
`scripts/bundle-fonts.mjs`; they do not run Python or fetch fonts.
Original fonts and license notices remain available for provenance.
